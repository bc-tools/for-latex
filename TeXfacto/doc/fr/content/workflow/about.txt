=======================
\Desc générale du \proj
=======================

Tout \pack \etou classe doit **obligatoirement** indiquer un certain \nbre d'\infos générales via un fichier path::''about.yaml''. Pour un codeur français, il est conseillé d'indiquer le contenu minimal suivant.

yaml::
    ---
    path  = ?/examples/archi/tutodoc/about.yaml
    title = Le fichier path::''about.yaml'' du projet \tutodoc du \tutodoc_date.
    ---


Le contenu du fichier path::''about.yaml'' peut sembler minimal, mais c'est suffisant car les outils automatisés "devinent" certaines choses.

    1) Le nom du \pack \etou de la classe est juste celui du dossier contenant le code \src : si besoin, certaines modifications seront faites pour obtenir un nom conforme à ce qu'accepte \latex.

    1) Suivant le type de fichiers codés dans le dossier path::''src'', il est aisé de savoir si le projet est celui d'un \pack \etou d'une classe.

    1) La date de création et le \numver en cours, lui aussi daté, sont des \infos déjà indiquées dans les journaux des \chgts \techs
    ((
        Voir cf::''?/workflow/changes.txt''.
    )).

    1) Les dépendances sont repérées \auto^t dans les codes des fichiers ext::''sty'' \etou ext::''cls''
    ((
        Voir cf::''?/workflow/src.txt''.
    )).

    1) La langue par défaut est l'anglais ; ceci nous évite ici d'indiquer la langue utilisée pour le fichier \readme et la \doc \tech, mais par contre, cela nous impose d'indiquer que la \doc "utilisateur" est en français.


Avec toutes ces \infos utiles découvertes, et en supposant que le code \src ne contient que des fichiers ext::''cls'' de \dev, les lignes suivantes seront produites \auto^t dans le fichier ext::''cls'' final
((
    Bien entendu, un travail similaire sera fait pour un package \latex, ou un projet utilisant le même nom pour un package et une classe.
)).

latex::
    ---
    path  = ?/examples/archi/tutodoc/start.cls
    title = Le début du fichier path::''tutodoc.cls'' le \tutodoc_date.
    ---


Voici la spécification complète, en français, du fichier path::''about.yaml''.

yaml::
    ---
    path = ?/examples/archi/full-main-about.yaml
    ---
