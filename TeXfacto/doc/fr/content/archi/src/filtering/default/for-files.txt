=================
Pour les fichiers
=================

Considérons le dossier de \dev ci-après (nous parlerons de l'usage d'un fichier path::''about.yaml'' dans cf::''?/with-about/for-files.txt'').

dirtree::
    ---
    path  = ?/examples/archi/tutodoc/dirtree/filtering/src/files-no-about.txt
    title = Le sous-dossier path::''src/admonitions'' de \tutodoc sans fichier path::''about.yaml'' - Une version simplifiée
    date    = \tutodoc_date
    ---


Dans ce type de situtation, \thisproj tient compte de tous les fichiers directement dans le dossier path::''src/admonitions'' en les classant de façon naturelle, et il considère les dossiers juste utiles pour des ressources du code \src ou de la \doc : voir cf::''?/resources.txt''.


note::
    On comprend ici que les fichiers de débogage path::''debug-*.tex'' ne sont pas destinés à être publiés.
    Pour les ignorer, il suffit d'employer yaml::''ignore: debug-*'' dans le path::''about.yaml'' du projet : voir cf::''?/metadata.txt''.
    On pourrait aussi ignorer de tels fichiers vis-à-vis de \git via le \gitignore, mais cette seconde \sol a le gros inconvénient de ne plus faire apparaître les fichiers de débogage dans le code \src sur le site de dépôt.
