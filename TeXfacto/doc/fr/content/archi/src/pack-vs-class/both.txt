================================
Un \pack et une \cls de même nom
================================

L'existence des fichiers path::''main/main.sty'' path::''main/main.cls'' indique un projet aboutissant à un \pack et une \cls homonyme.
C'est le cas dans le dossier path::''src'' fictif basique ci-dessous où la possibilité de coder deux \docs différentes pour le \pack et la \cls n'est pas utilisée
((
    Nous reviendrons sur ce point dans cf::''?/docs.txt''.
)).
Noter l'utilisation de fichiers ext::''cls.sty'' codant les fonctionnalités pour la \cls, et ceux juste de type  ext::''sty'' à destination du \pack.

dirtree::
    ---
    path  = ?/examples/archi/coding/dirtree-both.txt
    title = Un dossier path::''src'' fictif.
    ---


La fabrication du \proj final aboutira à deux fichiers ext::''cls'' et ext::''sty'' de même nom en collant les bouts de code comme suit.

    + Pour l'unique fichier ext::''sty'', les morceaux de code seront collés comme suit.

        1) path::''main/main.sty''

        1) path::''alpha-et-omega3/alpha.sty''

        1) path::''poor-lonesome-cowboy/lucky.sty''

    + Pour l'unique fichier ext::''cls'', les morceaux de code seront collés comme suit.

        1) path::''main/main.cls''

        1) path::''alpha-et-omega3/omega3.cls.sty''

        1) path::''poor-lonesome-cowboy/rantanplan.cls.sty''
