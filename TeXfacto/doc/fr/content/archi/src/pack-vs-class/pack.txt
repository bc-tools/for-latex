===============
Un simple \pack
===============

Considérons le dossier path::''src'' fictif basique suivant

Voici ce qu'il faut faire pour coder un package \latex.

    1) Le fichier path::''src/preamble.cfg.sty'', et les fichiers ext::''tex'' directement dans les sous-dossiers sont destinées à la \doc "utilisateur" : ce sujet est abordé dans cf::''?/docs.txt''.

    1) Le \dev "morceau par morceau" se fait directement dans le sous-dossier path::''src''. Il est interdit de passer via des "sous-sous-dossiers".

    1) Chaque fichier ext::''sty'' codant un morceau du package doit se trouver dans un sous-dossier de profondeur '1' de path::''src''.

    1) A minima, il faudra \tjrs coder un fichier path::''main/main.sty''. D'un point de vue pratique, ce fichier va centraliser les importations de \packs, et la gestion des options du package.


Lors de la fabrication du \proj final, les fichiers \src seront collés dans un unique fichier ext::''sty'' en respectant l'ordre "naturel" suivant
((
    Pour le processus de fabrication finale, voir cf::''?/workflow/build.txt''.
)).

    1) path::''main/main.sty''

    1) path::''alpha-et-omega3/alpha.sty''

    1) path::''alpha-et-omega3/omega3.sty''

    1) path::''poor-lonesome-cowboy/lucky.sty''


caution::
    Bien noter que l'on travaille directement dans un sous-dossier sans passer via des sous-sous-dossiers, et qu'il faut \tjrs utiliser un fichier path::''main/main.sty''.
