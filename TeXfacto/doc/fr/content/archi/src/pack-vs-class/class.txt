===============
Une simple \cls
===============

Voici dossier path::''src'' fictif basique similaire à celui présenté pour coder un \pack.

dirtree::
    ---
    path  = ?/examples/archi/coding/dirtree/class.txt
    title = Un dossier path::''src'' fictif.
    ---


Le principe est similaire au \dev d'un \pack aux deux différences importantes suivantes.

    1) A minima, il faudra \tjrs coder un fichier path::''main/main.cls''. D'un point de vue pratique, ce fichier va centraliser les chargements de \clss, les importations de \packs, et la gestion des options de la classe.

    1) Les fonctionnalités spécifiques seront codées dans des fichiers ext::''cls.sty'', et non ext::''sty''. Voici pourquoi.

        + Ceci permet en interne de charger la classe path::''main/main.cls''.

        + Les fichiers ext::''cls.sty'' sont importables via latex::''\usepackage'', ceci permettant d'utiliser latex::''@'' comme caractère non actif dans le code \src.


Ici la fabrication du \proj final aboutira à un unique fichier ext::''cls'' en collant les bouts de code via l'ordre "naturel" suivant.

    1) path::''main/main.cls''

    1) path::''alpha-et-omega3/alpha.cls.sty''

    1) path::''alpha-et-omega3/omega3.cls.sty''

    1) path::''poor-lonesome-cowboy/lucky.cls.sty''
