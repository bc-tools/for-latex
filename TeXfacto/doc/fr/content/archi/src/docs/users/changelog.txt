=====================
Le journal des \chgts
=====================

caution::
    Tout \proj doit utiliser un dossier path::''change'' où indiquer les \chgts liés au code \src. Dès lors, \thisproj lèvera une erreur en cas de non cohérence entre les \chgts stables côté path::''change'', et ceux rédigés dans path::''src/changelog'' qui sont présentés dans cette section.


Pour la \mandoc, les \chgts "stables" doivent être renseignés via une \orga similaire à la suivante.

dirtree::
    ---
    path  = ?/examples/tutodoc/changes/dirtree/old/changelog.txt
    title = Le dossier path::''src/changelog'' de \tutodoc
    date  = \tutodoc_date_OLD
    ---


Expliquons un peu la scène du crime en commençant par les fichiers path::''test_one_date.tex'' et path::''next.tex'' qui se construisent via \thisproj.
Le fichier path::''next.tex'' est initialement vide, tandis que le contenu du fichier path::''test_one_date.tex'' produit par \thisproj est le suivant.

latex::
    ---
    path  = ?/examples/archi/doc/test_one_date.tex
    title = Code de path::''test_one_date.tex'' produit auto^t.
    ---


Dans ce fichier, directement compilable, une date à tester se règle via les lignes suivantes où le fait de choisir un numéro de jour nul, par exemple, en décommentant la ligne latex::''%\renewcommand\docday{0}'', indique de tester le contenu du fichier path::''next.tex''. L'utilité de ce dernier est de permettre la \redac à la demande des \chgts avant même que la version stable soit publiée.

latex::
    ---
    path    = ?/examples/archi/doc/test_one_date-settings.tex
    extract = yes
    title   = Tester le contenu pour une date précise.
    ---


Les autres fichiers servent à indiquer les \chgts pour un jour donné à l'intérieur d'un dossier "mois", lui-même contenu dans un dossier "année". La méthodologie à suivre est la suivante.

    1) Si plusieurs versions sont publiées le même jour
    ((
        Penser à un bug critique vite découvert.
    )),
    il faudra suffixer le numéro du jour avec path::''-a'', path::''-b'', path::''-c''...

    1) Comme \thisproj connaît les \chgts indiqués dans path::''change'', les numéros de version n'ont pas à être indiqués lors de la \redac de la \mandoc.
