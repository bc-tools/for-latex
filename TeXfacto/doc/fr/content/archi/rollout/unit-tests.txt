=======================
Tests de non régression
=======================

Grâce à \l3build, il est aisé de tester de façon automatisée la non régression d'un \proj \tex. Ces tests sont à placer dans le dossier path::''tests''.
Nous renvoyons le lecteur intéressé à la \doc de \l3build pour apprendre à coder des fichiers tests comme les suivants.


latex::
    ---
    path    = ?/examples/tutodoc/rollout/l3build-test-pdf.lvt
    extract = start
    title   = Un fichier de test utilisé par \tutodoc
    date    = \tutodoc_date
    ---


latex::
    ---
    path    = ?/examples/tutodoc/rollout/l3build-test-no-pdf.lvt
    extract = start
    title   = Un autre fichier de test utilisé par \tutodoc
    date    = \tutodoc_date
    ---


note::
    L'auteur de \thisproj a mis en ligne quelques fonctions \lua pouvant faciliter la gestion des tests de non régression.
    Par exemple, une fonction \lua est proposée pour faciliter l'enquête si le fichier de tests précédent échoue : voir le dossier path::''src/cmd-options/unit-test/showbox'' du dépôt \l3buildxtras.
