=====================
Déboguer les \mandocs
=====================

Le processus de \redac de la \mandoc permet d'effectuer indirectement des tests d'utilisation
((
    Voir cf::''?/docs/users.txt''.
)).
Ces tests peuvent ne plus fonctionner lorsque l'on intègre l'\ens du code \src et de la \doc.
Pour aider à déboguer à la main ce type de \pbs, \thisproj met dans le dossier path::''debug'' le code \src et les fichiers ext::''tex'' des \mandocs finalisés afind e permettre au \dev de compiler à la main la \mandoc avec le code \src fabriqué.
